SysWatch

Know what is slowing your Mac down.

A tiny menu bar app that watches memory, CPU, threads and disk. It names the app causing the slowdown and lets you quit it in one click.

Download for Mac

Version 1.0.1 · macOS 14 Sonoma or later · Apple silicon and Intel · 1 MB

Or install with one command

curl -fsSL https://github.com/rishavkr08/SysWatch/releases/latest/download/install.sh | sh

Paste it into Terminal. It checks the download's checksum, installs to Applications and opens the app, with no security prompt to approve.

What it does

See the bottleneck at a glance

A green, orange or red dot in the menu bar. Ring gauges for CPU, memory and disk, each with a ten-minute trend, and a memory breakdown that shows how much is compressed or swapped.

Processes grouped by app

Chrome's 60 helper processes appear as one 7.6 GB row, so the real offender stands out. Quit a whole app, or expand it and quit one process.

Alerts before the freeze

Notifications when memory, swap, sustained CPU, thread count or free disk cross your limits. Each alert names the top process and has a Quit button.

Ask Claude to fix it

When a Claude Code session started the heavy process, one click copies a prompt with the command, its memory use and the project, ready to paste into that session.

Installing from the download

  1. Open SysWatch.dmg and drag SysWatch into the Applications folder.
  2. Open SysWatch from Applications. A dot with two percentages appears in the menu bar.
  3. When macOS asks whether SysWatch may send notifications, click Allow.
  4. Click the dot, then tick Launch at login in the panel's footer.

If macOS says it cannot verify the developer, open System Settings › Privacy & Security, scroll to the message about SysWatch, and click Open Anyway. You only do this once. The one-command install above skips this step.

SysWatch is free and has no tracking. It reads process stats on your Mac only and sends nothing anywhere. Release notes and checksums
